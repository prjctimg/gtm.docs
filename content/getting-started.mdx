## First run

```bash
# Start the TUI (gtmd spawns automatically in the background)
gtm
```

1. The **Library** view opens automatically — there are no tabs.
2. Press `Enter` on a category to drill down into a track list.
3. Press `Enter` on a track to play it.
4. Press `Space` to pause/resume; `n`/`p` for next/previous.
5. `Alt+,` opens Settings; `?` shows the full keybinding list.

The daemon writes its log to `$XDG_DATA_HOME/gtm/gtmd.log` (or
`~/.local/share/gtm/gtmd.log`), truncating it on every start. It persists
queue, volume, repeat mode, and crossfade settings across restarts in
`state.json`.
