## Layout

The TUI has a single workspace split into panes:

```
┌──────────────────────────────────────────────────────────┐
│  NOW PLAYING (top third)        ┌────────┐  ┌────────┐  │
│  cover art · title · progress   │        │  │ lyrics │  │
│                                 │ visual.│  │(≥100w) │  │
├──────────┬──────────────────────┤        │  └────────┘  │
│  sidebar │  results             │        │              │
│  (left)  │  (centre)            │        │              │
│          │                      └────────┘              │
├──────────┴──────────────────────────────────────────────┤
│  footer bar                                              │
└──────────────────────────────────────────────────────────┘
```

- **Now Playing** — cover art, animated marquee title, progress bar. Height
  adapts: 5 rows under 60 columns, 6 rows under 22 rows, otherwise
  `clamp(area_height / 3, 8, 14)`.
- **Sidebar** — 13 categories: All Tracks, Liked, Albums, Artists, Playlists,
  Spotify, Radio, Most Played, Recently Played, Recently Added, Genres, Folders,
  Top Charts. Shows item counts. Filter and reorder the list with
  `left_pane_lists` in `config.toml`.
- **Results pane** — tracks, albums, artists, playlists, genres, folders or
  chart entries depending on the selected category.
- **Visualizer** — shown right of Now Playing when enabled and terminal width
  ≥ 80 columns.
- **Lyrics pane** — shown when lyrics are loaded and terminal width ≥ 100
  columns.

![Interactive Terminal Layout & Playback Preview](/samples/terminal-player-demo.gif)

### Narrow terminals

When the terminal is narrower than 60 columns, the sidebar and results
collapses into a single pane. Focus is switched with `[` and `]`.

## Keybindings

Keybindings are split into three contexts:

| Context | When active |
|---------|------------|
| **Global** | Always active (quit, help, play/pause, next/prev) |
| **Normal** | Default mode (tab switching, cursor, volume, overlays) |
| **List** | When a list widget has focus (navigation, selection, deletion) |

The first matching binding wins.

### Global keys

| Key | Action |
|-----|--------|
| `Space` | Play / Pause |
| `n` | Next track |
| `p` | Previous track |
| `q` | Quit |
| `Q` / `Ctrl+Q` | Quit and stop daemon |
| `?` | Toggle help buffer |

### Normal / List keys

| Key | Action |
|-----|--------|
| `Tab` / `Shift+Tab` | Next / previous pane |
| `k` / `j` or `↑` / `↓` | Move up / down |

| `Home` / `End` or `gg` / `G` | Jump to top / bottom |
| `Enter` | Select / drill down |
| `Backspace` | Go back |
| `d` / `Del` | Remove item from list |
| `s` | Stop |
| `+` / `=` / `-` | Volume up / down |
| `>` / `<` | Speed up / down (pitch-preserving) |

## Custom keybindings

You can remap any binding in `config.toml` under the `[keybindings]` table.
The map is **key → action name** (not the other way round):

```toml
# ~/.config/gtm/config.toml
[keybindings]
"Space"  = "play_pause"
"Up"     = "volume_up"
"Alt+q"  = "open_queue"
"Ctrl+q" = "quit"
```

:::caution
The direction matters. Written the other way round (`play_pause = "Space"`),
every entry is rejected: the client tries to parse `play_pause` as a key, fails,
prints `gtm: unknown key "play_pause"` and silently drops the binding.
:::

Available action names include: `play_pause`, `next`, `prev`, `stop`,
`volume_up`, `volume_down`, `speed_up`, `speed_down`, `seek_forward`,
`seek_backward`, `toggle_shuffle`, `cycle_repeat`, `toggle_mute`,
`toggle_favourite`, `clear_queue`, `toggle_visualizer`, `toggle_theme`,
`cycle_sort`, `toggle_low_power`, `quit`, `quit_daemon`, `toggle_help`,
`hide_help_bar`, `open_queue`, `open_yt_search`, `open_search`,
`open_settings`, `open_spotify_search`, `open_equalizer`,
`open_progress_style`, `open_visualizer_preset`, `open_theme_picker`,
`open_about`, `open_sleep_timer`, `open_command_palette`, `open_setup`,
`open_notifications`, `open_radio`, `open_radio_browse`, `open_podcast`,
and more. `toggle_low_power` has **no default key binding** — this is the only
way to reach low-power mode from the keyboard.

:::note
User bindings bind in Normal + List contexts only. Global keys (`q`, `?`,
`Space`) are checked first and cannot be overridden via config.
:::

## Command palette

Press `:` to open the command palette. It lists 47 of the available actions
with an icon (Material Design Icons by default; any non-`mdi` value of
`icon_style` gives the emoji set). Type to filter, then press `Enter` to
execute.

---

## Help buffer

Press `?` to open a full-screen help buffer. It is a static list of every
default keybinding, grouped by topic (Playback, Navigation, Playlists, View,
Queue, System). It contains no configuration reference and no setup
instructions — see [Configuration](/configuration/) for that.

`j`/`k`/arrows scroll, `G`/`$` jump to the end, `0`/`Ctrl+g` to the top, and
`n`/`N` step one line. Close it with `Esc` (`q` does nothing here).

## Picker overlays

When a picker is open (Queue, YouTube Search, Equalizer, Theme Picker, etc.):

- `j` / `k` or `↑` / `↓` — navigate
- `Enter` — select
- `Esc` — close
- Type to filter (where supported)

The Sleep Timer picker offers quick options (5, 10, 15, 30, 60, 90, 120 min)
and manual numeric input. The Crossfade picker offers 3, 5, 10, 15, and 30
second presets.

## Mouse

Mouse support is provided by the TUI runtime:

- **Single click** — select item in a list
- **Double click** (within 400 ms) — play selected track
- **Scroll** — navigate in list widgets

Mouse capture follows the terminal's alt-screen state. When a picker overlay
is open, clicking outside the picker closes it.

## Footer bar

The footer bar sits at the bottom and shows status modules arranged in two
groups (left and right). Modules are small colored badges with accent
backgrounds.

### Available modules

| Module | Shows |
|--------|-------|
| `Playback` | Play / Pause / Stop icon |
| `Title` | Current track title (marquee) |
| `Volume` | Volume percentage |
| `Speed` | Current playback rate |
| `Repeat` | Repeat mode (Off / One / All) |
| `Shuffle` | Shuffle on/off |
| `Progress` | Mini progress bar |
| `Queue` | Queue length |
| `KeyAction` | Last action name (set `footer_key_action = "keys"` for the key) |
| `Backend` | Audio backend (Rodio / PulseAudio) |
| `System` | Platform icon |
| `EqPreset` | Current EQ preset name |
| `SleepTimer` | Remaining sleep time |
| `LowPower` | Low-power mode indicator |
| `Mono` | Mono downmix indicator |
| `Device` | Active audio device |
| `Notification` | Notification badge |
| `Time` | Clock |
| `Multiselect` | Selection count |
| `Download` | Download progress |
| `Network` | Network status |
| `Source` | Active source provider |

### Footer presets

Three built-in presets are shipped: **Default**, **Minimal**, and **Full**.

You can define custom presets in `~/.config/gtm/footer.toml`:

```toml
[[preset]]
name = "My Preset"
left = ["Playback", "Volume"]
right = ["Time", "Backend"]
```

User presets replace built-in presets with the same name. Unknown module
names are silently dropped so typos never break the bar.

Toggle the bottom help/hint bar on/off with `Ctrl+H`.

## Limitations

- **Visualizer** requires terminal width ≥ 80 columns.
- **Lyrics third pane** requires terminal width ≥ 100 columns.
- **Terminals under 20×6** show a size warning and may not render correctly.
- **Image cover art** is disabled in Neovim (`$NVIM`) and Zellij (`$ZELLIJ`)
  terminals due to incompatible alternate-screen protocols.
- Keybindings are hot-reloaded: the client re-reads `config.toml` on the
  next frame, so edits apply without a restart.
