## Files layout

gtm follows XDG conventions. All paths below assume the default XDG base
directories:

| Path | Contents |
|------|----------|
| `~/.config/gtm/config.toml` | TUI preferences |
| `~/.config/gtm/themes/*.toml` | User theme files |
| `~/.config/gtm/footer.toml` | Custom footer presets |
| `~/.config/gtm/radios.toml` | Custom radio stations |
| `~/.config/gtm/spotify.json` | Spotify access/refresh token (mode 0600) |
| `~/.config/gtm/spotify_client_id` | Spotify Web API app id, when not set by env |
| `~/.config/gtm/spotify_playlists.json` | Spotify playlist sync snapshot |
| `~/.config/gtm/secrets/` | Plaintext secret fallback when no OS keychain |
| `~/.local/share/gtm/state.json` | Persistent daemon state |
| `~/.local/share/gtm/library.db` | SQLite library database |
| `~/.local/share/gtm/gtmd.log` | Daemon log |
| `~/.local/share/gtm/audio/` | Default library scan directory (see below) |
| `~/.local/share/gtm/*.m3u8` | Playlist mirror stubs |
| `~/.cache/gtm/covers/` | Album cover cache (see `cover_cache_mb`) |
| `~/.cache/gtm/artist_covers/` | Artist portrait cache |
| `~/.cache/gtm/lyrics/` | Offline lyrics cache |
| `~/.cache/gtm/spotify/` | yt-dlp audio cache for the Spotify→YouTube fallback |

On a fresh install the daemon scans, in order, `~/.local/share/gtm/audio/`,
`~/Music` (only if it already exists) and, under Termux, the shared-storage
music directories. `gtmd --library` does **not** change this list.

:::note
If `$XDG_CONFIG_HOME` is not set, `~/.config` is used. If `$XDG_DATA_HOME`
is not set, `~/.local/share` is used. On first run the daemon creates the
config, data and cache roots (and the parents of its sockets and log), along
with the `covers/` and `artist_covers/` cache directories. The rest —
`themes/`, `lyrics/`, `spotify/` — are created lazily on first use, and
`~/.config/gtm/themes/` is only created if you put a theme file there
yourself.
:::

## config.toml reference

The client reads `$XDG_CONFIG_HOME/gtm/config.toml` (or
`~/.config/gtm/config.toml`). It is hot-reloaded: the file's mtime is re-checked
every 120 frames (~2 s at 60 fps) and changes take effect on that tick.

A `config.toml` is written the first time you run `gtm config` or change a
setting in the TUI. Launching `gtm` on its own only ever reads it.

:::caution
Because the whole file is re-read on each reload tick, write it atomically
(temporary file + rename) — a partially written file can be read mid-write.
:::

:::caution
Enum values are **case-sensitive** and several have no serde rename, so they
must match exactly: `progress_style` takes `SeekHead` / `Classic` / `Dots` /
`TrueGradient`, and `track_sort` takes `Recents` / `RecentlyAdded` /
`Alphabetical` / `Artist` / `Album`. A single invalid value does not fail just
that key — the **entire file is discarded and defaults are used**, silently and
with no log line. Run `gtm config --validate` to check a file before relying on it.
:::

```toml
# ─── Theme ───────────────────────────────────────────────────────────
theme_name = "Chadrula"          # Built-in or user theme name
theme_mode = "auto"              # "auto" | "dark" | "light" | "manual"
transparent_bg = false           # Transparent terminal background
transparent_pickers = false      # Transparent picker overlays
reactive_theme = false           # Derive accents from cover art
reactive_theme_intensity = 0.34  # Background wash strength (0.0–1.0)

# ─── Footer ──────────────────────────────────────────────────────────
footer_preset_name = "Default"   # Footer layout preset
footer_key_action = "action"     # "action" (name) | "keys" (the key)
hide_footer = false              # Hide the footer bar entirely

# ─── Progress & Visualizer ──────────────────────────────────────────
progress_style = "TrueGradient"  # "SeekHead" | "Classic" | "Dots" | "TrueGradient"
visualizer_preset = "braille"    # one of 12, see below

# ─── Display ─────────────────────────────────────────────────────────
time_format = "%H:%M"            # strftime format for the clock
icon_style = "mdi"               # "mdi" (nerd fonts); any other value = emoji set

# ─── Cover & Lyrics ─────────────────────────────────────────────────
cover_provider = "auto"          # "auto" | "deezer" | "mb" | "spotify"
                                # ("mb" also accepts "musicbrainz")
cover_cache_mb = 512             # Combined covers/ + artist_covers/ budget
auto_fetch_lyrics = true         # Auto-fetch lyrics on track change

# ─── Library ─────────────────────────────────────────────────────────
track_sort = "Recents"           # "Recents" | "RecentlyAdded" | "Alphabetical"
                                # | "Artist" | "Album"
left_pane_lists = []             # Sidebar categories to show; empty = all 14
show_preview = true              # Left-pane track preview card

# ─── Notifications ──────────────────────────────────────────────────
[notification_modes]
playback = "footer"              # "floating" | "footer" | "off"
nowplaying = "footer"
library = "footer"
# ... one entry per notification category
# (playback, prefs, nowplaying, library, downloads, spotify, podcast,
#  radio, lastfm, system)

# ─── Extensions ─────────────────────────────────────────────────────
[extensions]
visualizer = true                # Optional TUI surfaces, on by default
floating_notifications = true
notifications_overlay = true

# ─── Keybindings ────────────────────────────────────────────────────
[keybindings]
# Key → action, not action → key. See interface.mdx.
"Space"  = "play_pause"
"Alt+q"  = "open_queue"
"Ctrl+q" = "quit"

# ─── Daemon ─────────────────────────────────────────────────────────
# Read by gtmd, not by the TUI. See "Daemon-read keys" below.
web_addr = "127.0.0.1:8991"      # Read-only JSON status endpoint; "" = off
```

### Field reference

| Key | Type | Default | Description |
|-----|------|---------|-------------|
| `theme_name` | string | `"Chadrula"` | Active theme name |
| `theme_mode` | string | `"auto"` | `auto` follows the OS setting, probing `GTM_THEME_MODE`, GNOME `gsettings`, `GTK_THEME`, then Omarchy's `colors.toml` (falling back to `theme_name` if none answer); `dark` / `light` pin the mode; `manual` always uses `theme_name` |
| `transparent_bg` | bool | `false` | Use terminal background (no fill) |
| `transparent_pickers` | bool | `false` | Transparent picker overlays |
| `reactive_theme` | bool | `false` | Derive accents from cover art |
| `reactive_theme_intensity` | float | `0.34` | Background wash strength; TUI cycles 0.15/0.25/0.34/0.45/0.6 |
| `footer_preset_name` | string | `"Default"` | Active footer preset: `Default`, `Minimal`, `Full`, or a user preset |
| `footer_key_action` | string | `"action"` | `action` renders the last action name, `keys` the key |
| `hide_footer` | bool | `false` | Hide the footer bar |
| `progress_style` | string | `"TrueGradient"` | `SeekHead` / `Classic` / `Dots` / `TrueGradient` |
| `visualizer_preset` | string | `"braille"` | `braille`, `blocks`, `mirror`, `gradient`, `spectrum`, `barsdot`, `classicpeak`, `columns`, `wave`, `stereo`, `retro`, `flame` |
| `time_format` | string | `"%H:%M"` | Clock format |
| `icon_style` | string | `"mdi"` | Only `mdi` is special-cased; anything else gives the emoji set |
| `cover_provider` | string | `"auto"` | `auto` / `deezer` / `mb` or `musicbrainz` (also `musicbrainz/cover-art-archive`) / `spotify` |
| `cover_cache_mb` | int | `512` | Combined on-disk budget over `covers/` **and** `artist_covers/`, oldest evicted first; TUI offers 128/256/512/1024/2048 |
| `auto_fetch_lyrics` | bool | `true` | Auto-fetch lyrics on track change |
| `track_sort` | string | `"Recents"` | `Recents` / `RecentlyAdded` / `Alphabetical` / `Artist` / `Album` |
| `left_pane_lists` | array | (all 14) | Sidebar categories to show, in display order; unknown names are dropped and an empty result falls back to all 14 |
| `show_preview` | bool | `true` | Left-pane track preview card |
| `notification_modes` | table | (all `"footer"`) | Per-category notification mode |
| `extensions` | table | (all `true`) | Optional TUI surfaces |
| `keybindings` | table | (empty) | Key → action remappings |
| `web_addr` | string | `"127.0.0.1:8991"` | Daemon status endpoint; read by `gtmd` only |

`left_pane_lists` accepts exactly these 14 names, and only in this spelling:
`All Tracks`, `Liked`, `Albums`, `Artists`, `Playlists`, `Spotify`, `Radio`,
`Most Played`, `Recently Played`, `Recently Added`, `Genres`, `Folders`,
`Top Charts`, `Podcasts`.

### Daemon-read keys

Everything above is the TUI's own configuration. `gtmd` reads the same file for
just three keys, and reads them at startup — changing any of them needs a daemon
restart, unlike the hot-reloaded settings above.

| Key | Default | Effect on the daemon |
|-----|---------|----------------------|
| `cover_provider` | `"auto"` | Which artwork source to query first. Anything unrecognized falls back to `auto` rather than failing |
| `cover_cache_mb` | `512` | On-disk budget for `covers/` + `artist_covers/`. Ignored when not a positive integer |
| `web_addr` | `"127.0.0.1:8991"` | Read-only JSON status endpoint, below |

### Status endpoint

`gtmd` serves a single `GET /status.json` (or `GET /`) — `HEAD` returns the
headers alone, any other verb gets a 405, and any other path a 404. It exists so
a script or widget can read what is playing without attaching to the IPC socket:

```json
{
  "playing": true,
  "track": {
    "title": "Teardrop",
    "artist": "Massive Attack",
    "album": "Mezzanine",
    "duration": 330.0,
    "position": 42.5,
    "remaining": 287.5,
    "cover_url": "/tmp/gtm-cover-abc.jpg"
  }
}
```

`track` is `null` when nothing is loaded, `remaining` is `null` for a live stream
with no end, and `cover_url` falls back to the cached cover's local path when the
provider gave no URL. There is no queue, history or file path in the payload — it
is the current track and nothing else. A bind failure is logged and playback
carries on: the endpoint is an extra surface, never a dependency.

:::caution
The payload is the current track, which is your listening history. It defaults
to loopback for that reason. `web_addr = "0.0.0.0:8991"` publishes it to your
LAN, and a bare `"8992"` is shorthand for loopback on that port. Set it to `""`
to turn the endpoint off.
:::

## Theme files

User themes are TOML files placed in `~/.config/gtm/themes/`. Each file
defines one theme. User themes replace built-in themes with the same name.

```toml
name = "My Theme"
# 18 required fields: `name` plus the 17 colours below
bg = "#1a1b26"
picker_bg = "#24283b"
fg = "#c0caf5"
fg_dim = "#565f89"
fg_bright = "#a9b1d6"
accent = "#7aa2f7"
error = "#f7768e"
warning = "#e0af68"
success = "#9ece6a"
selection_fg = "#1a1b26"
selection_bg = "#7aa2f7"
border = "#414868"
border_active = "#7aa2f7"
volume_low = "#9ece6a"
volume_medium = "#e0af68"
volume_high = "#f7768e"
sidebar_active_border = "#7aa2f7"
# optional
light = false
pane_bg = "#1a1b26"
elevated_bg = "#24283b"
muted_border = "#414868"
secondary_accent = "#bb9af7"
tertiary_accent = "#9ece6a"
notification_border = "#7aa2f7"
monochromatic = false
```

A file missing any of the 18 required fields is **silently skipped** — see
[Theming](/theming/) for the full schema. The `light` flag is auto-detected from
the background color's luminance if omitted. All color fields accept `#rrggbb`
hex.

## Footer presets

Custom footer presets are defined in `~/.config/gtm/footer.toml`:

```toml
preset = [{ name = "My Preset", left = ["Playback", "Volume", "EqPreset"], right = ["Queue", "Time", "Backend"] }]
```

Use any of the module names listed in the [Footer bar](/interface/#footer-bar)
section. Unknown names are silently dropped.

## Custom radio stations

Stations added with `gtm radio add` are stored in
`~/.config/gtm/radios.toml`:

```toml
station = [{ name = "NTS Radio", url = "https://stream-relay-geo.ntslive.net/stream" }]
```

Each station is referenced by `custom:N` where `N` is its 1-based index. Manage
the file with [`gtm radio add`](/cli/#radio), `gtm radio list` and
`gtm radio rm`.

Two further keys are optional per station: `uuid` (the Radio Browser
`stationuuid`, written automatically when a directory station is saved from
the TUI, so the playable URL and favicon can be re-resolved later) and
`tracklist` (a now-playing/recent-tracks endpoint, which overrides the
built-in source registry).

## Environment variables

| Variable | Used by | Description |
|----------|---------|-------------|
| `HOME` | Client, daemon | Base for the default config, data, cache and state paths |
| `XDG_CONFIG_HOME` | Client, daemon | Config directory root (default: `~/.config`) |
| `XDG_DATA_HOME` | Daemon | Data directory root (default: `~/.local/share`) |
| `XDG_CACHE_HOME` | Daemon | Cache directory root (default: `~/.cache`) |
| `XDG_STATE_HOME` | Client | Probed for the Omarchy `colors.toml` theme file |
| `XDG_RUNTIME_DIR` | Client, daemon | Derives the default IPC socket path |
| `TMPDIR`, `USER` | Client, daemon | Fallbacks for socket and state paths |
| `GTM_THEME_MODE` | Client | Force OS-theme detection to `dark` / `light`; honored only when `theme_mode = "auto"` |
| `GTM_NERD_FONTS` | Client | Set `0` / `false` / `no` to force plain-ASCII glyphs |
| `GTM_YT_HOSTS` | Daemon | Register extra YouTube-family search providers |
| `GTM_SPOTIFY_PORT` | OAuth flow | Override the Spotify callback port (default: 8990) |
| `GTM_SPOTIFY_CLIENT_ID` | Daemon | Spotify Web API app id; falls back to the bundled id file, then librespot's |
| `GTK_THEME` | Client | Second-choice OS theme probe; a trailing `-dark` means dark |
| `NVIM` / `ZELLIJ` | Client | Set either to disable cover art rendering — the terminal cannot show images |
| `VISUAL` / `EDITOR` | Client | Editor used by `gtm config` when it opens the file |
| `RUST_LOG` | Daemon | Controls log verbosity (`gtm=debug`, etc.); overrides `--verbose` |
| `PREFIX` / `TERMUX_VERSION` | Daemon | Termux detection, affects backend selection |

## Command-line flags

The two binaries take flags too, and they are documented separately: see
[CLI Reference](/cli/) for every `gtm` command and for `gtmd`'s options. The two
that matter most when you are pointing gtm at a non-default setup:

| Flag | Effect |
|------|--------|
| `gtm config` | Opens this file in your editor; `--reset` rewrites it from defaults, `--validate` checks it |
| `gtmd --config <DIR>` | Relocates the config, data **and** cache roots at once, overriding every XDG variable — useful for a throwaway instance |

:::note
`gtm config --validate` is the check to reach for after hand-editing this file.
A bad enum value does not fail just that key: the whole file is discarded and
defaults are used, silently.
:::
